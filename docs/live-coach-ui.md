# Live coach and meeting agents

Tuck extends its existing quiet assistant pane. Live coach is off for every call until the user chooses up to three saved agents and explicitly enables them. Settings → Intelligence contains a quiet meeting helper and an active Sales coach, plus a small inline editor for custom names, instructions and quiet/active pacing. Editing profiles does not enable coaching. Up to eight profiles can be saved; the core also validates the combined instruction size of the chosen profiles before activation.

The coach shows at most three open suggestions, each with its agent name and a transcript timestamp. Questions and insights are suggestions to consider. Follow-ups and reminders offer Save follow-up; this creates a task for user review without guessing an owner or date. A suggestion can be dismissed. Saved feedback identifies the Tasks destination. The core's 24-item limit describes retained suggestion history, not a lifetime cap on generated advice.

Selected active-agent names remain visible beneath the live status. The per-call Turn off control stays in the sticky heading, separately from scrolling manual chat. Paused recording and ended calls have explicit status copy. Ending a call removes the enable action; saved or still-open suggestions remain reviewable. Voice notes and built-in examples do not mount the feature. A short polite live-region count announces newly received suggestions without moving focus or reading the full card automatically.

The selected provider is disclosed at activation. Hosted processing requires the existing hosted-consent preference and names the automatically shared recent transcript excerpts, selected agent instructions and earlier tips. The current coach prompt does not include My notes. Manual Ask Tuck remains reachable during a coaching failure, but the error copy explains that manual chat uses the same AI connection; it does not promise a stopped model will answer. Background failures state that live coaching checks again automatically while enabled and link to AI settings. They do not present an immediate retry that bypasses native cadence/backoff. Failed foreground actions, such as saving a follow-up, retain their own explicit retry.

Agent editor drafts survive view changes for the current local webview session. A small sessionStorage record, with an in-memory fallback when that storage is unavailable, retains the one open draft. Other Edit actions stay disabled until Save or Cancel; inline guidance explains this. Explicit Cancel discards the draft, and successful save/removal clears it. This is session recovery, not a durable SQLite draft, backup feature, cross-device sync, or guarantee of recovery after quitting the application. Removing a saved profile first presents an inline Keep agent / Confirm removal choice; it does not introduce another modal.

No per-agent model, browser inference timer, sound, popup or automatic external action is introduced. Native scheduling owns inference; the component requests one initial status DTO and subscribes to `coach_updated`. A late status response cannot move suggestions into another selected meeting.

The existing cornflower actions, cool porcelain assistant surface, flat seams, system typography and inline settings controls are retained. The section adapts to the incumbent single-pane 390px layout without removing the composer or bottom navigation. Compact coach buttons/citations/dismiss controls and profile editor controls have minimum 40px target heights; citation and dismissal targets also have a 40px minimum width. Native mobile audio capture remains a separate qualification.
